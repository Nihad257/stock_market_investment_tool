# Stock Market Investment Tool

A simple Python desktop application that calculates personalized asset allocation (Equity and Gold) based on your age, monthly salary, and expenses.

## Features
*   User-friendly GUI built with Tkinter.
*   Calculates specific investment amounts based on percentages.
*   Available as a standalone Windows executable (.exe).

## How to Use
*   **Option 1 (Executable):** Go to the `dist` folder and double-click the `.exe` file to run the app instantly. (No Python needed).
*   **Option 2 (Source Code):** Make sure both `gui.py` and `app.py` are in the same folder. Run `python gui.py` in your terminal to start the app.

## Technologies Used
*   Python
*   Tkinter (for the GUI)
*   PyInstaller (to create the .exe file)
